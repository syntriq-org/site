A shared platform. A domain that stays yours.

ChargeWeave shows how industry definitions connect to a reusable application foundation.

ChargeWeave supplies the EV application

Its domain package defines charging entities, relationships, policies, workflows, measures and presentation. Settlement and correction journeys provide concrete examples of connected behaviour.

Syntriq supplies the mechanisms

The reusable layer handles supported queries, constraints, decisions, process coordination and engineering tools through explicit contracts. The core should not acquire hidden charging-specific branches.

Preserve behaviour as the boundary evolves

Technical development can continue inside ChargeWeave. Reference journeys and contract checks provide the basis for extracting reusable mechanisms into Syntriq without replacing domain definitions.
